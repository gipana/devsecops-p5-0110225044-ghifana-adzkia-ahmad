# DevSecOps P5 - Secure Web API

## 1. Nama Aplikasi & Fungsi
Aplikasi ini adalah **DevSecOps P5 Secure API**, sebuah layanan REST API sederhana berbasis Python yang menyediakan endpoint untuk pemrosesan teks dan validasi input secara aman.

## 2. Bahasa/Framework
- **Bahasa**: Python 3.10+
- **Framework**: Flask
- **Testing**: Unittest / Pytest
- **SAST Scanner**: Bandit (Python Security Analyzer)
